# Air Quality Analysis Using Python and Machine Learning

## Project Overview
This project focuses on analyzing air quality data using Python and Machine Learning. It uses the PRSA Aotizhongxin dataset collected from 2013 to 2017 to study air pollution and understand pollutant levels.

## Dataset
**Dataset Name:** PRSA_Data_Aotizhongxin_20130301-20170228.csv

The dataset contains air quality measurements, including:
- PM2.5
- PM10
- SO2
- NO2
- CO
- O3
- Temperature
- Pressure
- Humidity
- Wind Speed

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Objectives
1. Explore and understand the dataset.
2. Clean and preprocess the data.
3. Analyze air pollution levels.
4. Visualize data using graphs.
5. Apply Machine Learning algorithms for air quality prediction.
